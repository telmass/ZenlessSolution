## 1. 数据规模

| 图鉴 | 数量 | 数据源 | 字段 |
| --- | --- | --- | --- |
| 音擎 | 101 | 旧目录 `weapons.json` + `engines.auto.json` 图标 | 名称/评级/职业/基础攻击/高级属性/精炼 1–5 特效/获取方式/来源 |
| 驱动盘 | 30 | 旧目录 `drive-discs.json` | 名称/2 件套/4 件套/二件套面板 id/图标/来源 |
| 邦布 | 42 | gachabase `bangboo/beta`（中文名/图标/属性）+ 官方 WIKI 条目（技能/中文档案） | 中文名/英文名/代号/评级/图标/基础属性/主动技/额外能力/连携技/中文档案 |

生成链路：

```bash
python tools/import_codex.py        # data/sources -> src/data/codex/*.json + media 键
python tools/refresh_bangboo_wiki.py # 官方 WIKI：邦布技能 + 中文档案（手动、需联网）
python tools/sync_assets.py         # 172 个图鉴图标 -> public/assets/media/*.webp
python tools/check_data.py          # 数量 / 引用校验
python tools/check_assets.py        # 图标键 / 文件 / 体积校验
```

## 2. 页面结构

- 列表：标题 + 数量 + 搜索 + 评级/职业筛选 + 自适应网格（190px 起）。
- 音擎详情：大图标；基础攻击/高级属性；`R1–R5` 精炼切换；获取方式与官方 WIKI 链接。
- 驱动盘详情：2/4 件套效果（RichText 标签高亮）；4/5/6 号位主词条池；跳转菲欧妮配装计算器。
- 邦布详情：图标；代号/评级/英文名；8 项基础属性（生命/攻击/防御/冲击/暴击/暴伤/穿透/异常掌控）；主动技 / 额外能力 / 连携技（Lv.1 详细数据）；中文档案 + 英文原文。

## 3. 视觉与交互约定

- 复用全局 `codex.css`：网格卡片、筛选 chip、详情 hero、属性账本、邦布技能块。
- 图片全部本地 WebP，列表懒加载；无外链图。
- 音擎精炼状态在详情页本地切换；驱动盘主词条池复用 `core/panel/data`，不重复维护。
- 数据缺失时显示占位符，不伪造：邦布「梦游布」缺图标与 WIKI 条目，使用名称首字占位。

## 4. 已知缺口

1. **邦布「梦游布」**：官方 WIKI 尚未收录该条目，没有图标/技能/中文档案；列表与详情已明确显示占位。其余 41 只均有技能与中文档案（含「飚速布」，其 WIKI 条目为 287，总表 545 写作「飙速布」）。
2. **音擎「时光切片」** 的官方文本没有按精炼拆分，详情页显示合并描述并给出说明；其余 100 把均有 R1–R5。
3. 图鉴暂不做配装/适配角色推荐；只展示图鉴事实。
