# 攻略卡导出（PNG）

日期：2026-11-05
入口：代理人页 Hero 与「攻略」章节的 **保存攻略卡 / 复制攻略卡**。

## 1. 交付方式

| 按钮 | 行为 |
| --- | --- |
| 保存攻略卡 | 生成 PNG 并下载 `菲欧妮-攻略卡.png` |
| 复制攻略卡 | 生成 PNG 写入系统剪贴板；`ClipboardItem` 不可用时自动改为下载 |

不截整页 DOM，也不用 html2canvas；卡片由 `Agent` 数据直接绘制到 Canvas，避免受页面滚动、悬浮导航、响应式布局影响。

## 2. 卡片内容

尺寸 1200×1780 逻辑像素，2× 输出（2400×3560）：

1. **头图**：立绘、姓名、称号、属性/职业/评级/阵营、角色简介。
2. **技能加点**：六类技能等级与顺序箭头。
3. **影画**：L1–L6，关键影画高亮。
4. **音擎推荐**：攻略里的 5 把，含档位、精炼、局内 effect 摘要。
5. **驱动盘**：4 自由蓝调 + 2 法厄同，4/5/6 主词条与备选。
6. **队伍参考**：两支队伍，成员头像、定位。
7. **毕业面板**：54 / 30 词条两档，攻击 / 精通 / 掌控 + 有效词条口径。
8. **页脚**：数据来源、口径、生成时间。

所有图片走本地 `media()` 资源，不依赖远程 CDN，不会出现 canvas 污染。

## 3. 文件

- `src/lib/guide-card.ts`：Canvas 绘制、PNG Blob、下载、剪贴板。
- `src/components/GuideCardActions.vue`：两个按钮、进行中状态、`aria-live` 提示。
- 入口：`AgentHero.vue` 与 `GuideSection.vue`。

## 4. 已验证

- 通过页面按钮实际生成 PNG：**2400×3560，约 2.8 MB**。
- 卡片内 5 把音擎、2 支队伍、54/30 面板均完整渲染。
- 图片全部本地加载，无破图。

## 5. 已知限制

1. 卡片是固定版式；内容超长时按行截断（队伍说明加省略号）。
2. 不包含伤害对比表与 20s 轴；攻略卡聚焦「配装/养成」信息。
3. 复制到剪贴板需要安全上下文（https 或 localhost）；否则自动下载。
4. 没有自动化 Canvas 像素测试，保留生成尺寸/文件大小的手动验收。
