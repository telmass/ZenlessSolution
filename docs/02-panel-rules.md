# 局外面板计算规则（v1）

实现：`src/core/panel/compute.ts`；规则数据：`data/rules/panel.toml` → `src/data/panel.json`。
本文与代码不一致时，以代码和测试为准，并回头修正本文。

## 1. 计算范围

只算**局外面板**：角色基础、核心技的基础属性、音擎基础值与高级属性、驱动盘固定/主词条、二件套、副词条。

**不计入**（属于局内或条件效果）：

- 音擎特效（含精炼数值）；
- 核心被动本身（如菲欧妮「涅槃」的灼蚀暴伤）；核心技 A–F 的固定面板加成（异常掌控 / 基础攻击 / 异常精通 / 基础能量回复）计入；
- 驱动盘 4 件套效果；
- 需要触发条件的二件套（数据里 `effect2 = null`，如属性伤害类）；
- 战斗内 Buff、队友 Buff、环境效果。

## 2. 基础池与百分比

```text
生命 = (角色生命 + 核心基础生命 + 音擎基础生命) × (1 + 生命%) + 固定生命
攻击 = (角色攻击 + 核心基础攻击 + 音擎基础攻击) × (1 + 攻击%) + 固定攻击
防御 = (角色防御 + 核心基础防御 + 音擎基础防御) × (1 + 防御%) + 固定防御
冲击力 = (角色冲击力 + 固定冲击力) × (1 + 冲击力%)
异常掌控 = (角色掌控 + 核心掌控) × (1 + 掌控%)
能量回复 = (角色回能 + 固定回能) × (1 + 回能%)
暴击率 / 暴击伤害 / 增伤 / 穿透率 / 穿透值 / 异常精通 = 基础 + 加算
```

- 驱动盘 1/2/3 号位固定值：生命 +2200、攻击 +316、防御 +184，进入**固定值**侧。
- 核心 A/C/E 的「异常掌控 +12」进入**基础池**（先加后乘），不是百分比；B/D/F 的「基础攻击 +25」同理。
- 音擎基础攻击进入基础池；音擎高级属性（异常掌控 30% 等）进入百分比累加器。
- 音擎精炼只改特效，不改白值与高级属性，因此计算器里精炼不参与局外面板。

## 3. 异常掌控与回能的显示

- 异常掌控按完整精度计算（如 `152 × 1.68 = 255.36`），页面保留一位小数显示 `255.4`；不在中间步骤取整。
- 回能基础值以 `1.2` 存储，最终乘 100 显示为 `120%`。

## 4. 加成顺序

1. 核心技基础属性
2. 音擎基础值与高级属性
3. 驱动盘 1/2/3 固定值
4. 驱动盘 4/5/6 主词条
5. 副词条（条数 × 单条值）
6. 二件套（4 件套的 2 件套效果 + 2 件套）

明细按该顺序列出，便于核对。

## 5. 校验基准（与旧项目计算器一致）

## 6. 已知简化

- 按「6 件盘聚合」计算，不追踪每件盘的主副词条互斥；游戏内同一件盘的主副词条不能同名，但聚合模型无法表达。
- 不计算命破/锋御模式；当前已开放角色全部为通用面板。
- 二件套只支持 `data/rules/panel.toml` 中登记的 12 种面板类效果；其余套装在 UI 中提示「不计入局外面板」。
- 不处理小数条数：副词条按 `floor` 取整；输入侧按逐件盘约束（每盘 9 条、最多 4 种、单条 1–6 次），汇总后才进入面板公式。
- 副词条与同盘主词条不能同 `stat + kind`（1/2/3 号位固定主词条也参与：小生命 / 小攻击 / 小防御分别被挡）；同名词条全局上限 = `(6 − 主词条占用盘数) × 6`。
